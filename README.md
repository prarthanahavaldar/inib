📱 QR Code Scanner

A simple Android QR Code Scanner app developed using Kotlin and Android Studio as part of my Intern Infobyte Android Development Internship.

✨ Features

- 📷 Scan QR codes using the camera
- 🔦 Torch/Flashlight support
- 🖼️ Scan QR codes from gallery
- 🔍 Animated scan line
- 📄 Display scanned information
- 🔗 Open scanned URLs

🛠️ Technologies

- Kotlin
- Android Studio
- XML
- ZXing
- Git & GitHub

🎯 Internship Task

Task 1 – QR Code Scanner
Organization: Intern Infobyte
Domain: Android Development

🚀 How to Run

1. Clone this repository.
2. Open it in Android Studio.
3. Sync Gradle.
4. Run the app on an Android device.
5. Allow camera permission and scan a QR code.
