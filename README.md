📱 QR Code Scanner Android App

A simple and user-friendly QR Code Scanner Android application developed using Kotlin and Android Studio as part of my Android Development Internship at Intern Infobyte.

The application allows users to scan QR codes using the device camera, extract the information encoded in the QR code, display the scanned result, and open URLs when the scanned content contains a web link.

---

🎯 Project Objective

The main objective of this project is to develop an Android application that can:

- Scan QR codes using the device camera.
- Extract information encoded in QR codes.
- Display the scanned information to the user.
- Allow users to open scanned web links.
- Provide a simple and easy-to-use scanning interface.

---

✨ Features

📷 QR Code Scanning

Scan QR codes directly using the smartphone camera.

🔦 Flashlight / Torch

Turn the device flashlight on or off while scanning in low-light conditions.

🖼️ Scan QR Code from Gallery

Select an image containing a QR code from the device gallery and scan it.

🔍 Animated Scan Line

A scanning animation helps users understand where to position the QR code.

📄 Display Scanned Result

The information extracted from the QR code is displayed clearly on the screen.

🔗 Open Scanned URLs

If the QR code contains a website URL, users can open the link directly in their browser.

📱 Simple User Interface

The application provides a clean and easy-to-use interface for a better user experience.

🚀 How to Run the Project

1. Clone the Repository

git clone https://github.com/prarthanahavaldar/inib.git

2. Open in Android Studio

Open the cloned project in Android Studio.

3. Sync Gradle

Allow Android Studio to download and sync the required dependencies.

4. Connect an Android Device

Connect an Android smartphone using USB debugging or use an Android Emulator.

5. Run the Application

Click the Run ▶️ button in Android Studio.

6. Give Camera Permission

Allow the application to access the camera when prompted.

7. Scan a QR Code

Point the camera toward a QR code and wait for the application to detect it.
